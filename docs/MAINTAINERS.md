## How to Become a Maintainer

Null-Secret is an open-source project and welcomes community involvement. Becoming a maintainer requires demonstrating a deep understanding of the zero-knowledge security model and a history of high-quality contributions.

The general progression path is:
1. **Contributor:** Submitting high-quality PRs, fixing bugs, and improving documentation.
2. **Reviewer:** Actively reviewing other contributors' PRs and helping triage GitHub Issues.
3. **Maintainer:** Nominated by the Core Maintainer after sustained, trustworthy involvement.

If you are interested in taking on a larger role, please reach out via GitHub Discussions.
